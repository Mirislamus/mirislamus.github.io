# Анимации и фичи mirislamus.github.io

Дата: 30 сентября 2026 Статус: согласовано с владельцем, к реализации после фазы 2 [`tz.md`](./tz.md) (сайт уже на Astro без React).

Этот документ описывает, **что меняется визуально и что добавляется**. Инженерные требования (архитектура, бюджеты, тесты, CI, a11y-база) задаёт `tz.md` и здесь не повторяются: каждая фича обязана им соответствовать.

---

## 1. Принципы движения

Выбран стиль **«один яркий момент + сдержанно»**:

1. **Один wow-момент** — Hero-интро (F-02). Всё остальное — тонкие микровзаимодействия в духе Linear и Vercel.
2. **Анимируются только `transform`, `opacity`, `clip-path`.** Никаких анимаций `width`, `height`, `top`, `margin`, `box-shadow` на каждом кадре.
3. **Не больше одной непрерывной анимации в кадре.** Единственное исключение — Hero (волна 5): фоновый дождь (M-01) и «дыхание» жидкого аватара (M-03) идут от одного общего цикла `requestAnimationFrame` (M-00) и останавливаются одной кнопкой паузы (M-04). В остальных секциях новые бесконечные анимации не добавляются (пульс статуса — конечный, F-08).
4. **Эффекты за курсором** (наклон, реакция аватара, «фонарик» по дождю) работают только при `(hover: hover) and (pointer: fine)`. Исключения волны 5 с отдельной реакцией на касание: тап по аватару (M-03) и вспышки надписи под пальцем (M-05).
5. **`prefers-reduced-motion: reduce`** отключает всё движение: элементы сразу в конечном состоянии, функциональность сохраняется. Кнопка паузы (M-04) для эффектов волны 5 действует так же, как reduced motion.
6. **Без JS всё видно.** Стили начальных состояний анимаций включаются только при наличии соответствующего атрибута или `@supports`, контент никогда не остаётся скрытым.
7. **Без библиотек анимации.** CSS, Web Animations API, View Transitions, scroll-driven animations, Canvas 2D.
8. **Производительность:** 60 fps при 4× CPU throttling в DevTools; постоянный `will-change` запрещён.

### Волна 1. Фундамент и wow

#### F-00. Токены движения

- **Оценка:** 2 ч.
- **Что сделать:** в `_variables.scss` (поверх токенов из RF-16):
  - кривые: `--ease-out: cubic-bezier(0.16, 1, 0.3, 1)` (появления, раскрытия), `--ease-in-out: cubic-bezier(0.65, 0, 0.35, 1)` (перемещения), `--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1)` (только микроакценты: иконки, переключатели);
  - длительности: `--dur-fast: 150ms`, `--dur-base: 250ms`, `--dur-slow: 400ms`, `--dur-intro: 800ms`;
  - глобальный блок `@media (prefers-reduced-motion: reduce)`, обнуляющий длительности.
- **Приёмка:** все новые анимации используют только эти токены; stylelint запрещает «сырые» `cubic-bezier` и длительности вне `_variables.scss`.

#### F-01. Сдержанное появление при скролле

- **Оценка:** 2 ч.
- **Что сделать:** заголовки секций и группы карточек появляются один раз: `opacity 0 → 1`, `translateY(16px) → 0`, `--dur-slow`, `--ease-out`. Через `@supports (animation-timeline: view())` и `animation-range: entry 0% entry 40%`. В группах — задержка по индексу `--i × 40ms`, не больше 5 элементов. Абзацы текста не анимируются. Hero исключён (его ведёт F-02). Где нет поддержки — контент просто виден, JS-фолбэка нет.
- **Приёмка:** в Chrome/Edge секции появляются при скролле; в Safari/Firefox без поддержки всё видно сразу; CLS 0.

#### F-02. Hero-интро (wow-момент)

- **Оценка:** 6 ч.
- **Что сделать:**
  1. **Когда:** один раз за сессию вкладки. Блокирующий инлайн-скрипт в `<head>` (рядом со скриптом темы) проверяет `sessionStorage['intro-played']` и `prefers-reduced-motion`; если интро нужно, ставит `data-intro` на `<html>` до первой отрисовки. После окончания интро флаг записывается. Смена языка и перезагрузка в той же вкладке интро не показывают.
  2. **Хореография (≈1.1 с):**
     - 0–500 мс: аватар `scale(0.94) → 1`, `opacity 0 → 1`;
     - 150–650 мс: `h1` по словам — `translateY(100%) → 0` внутри маски (слова оборачиваются в `<span>` при сборке в Astro, без JS);
     - 450–750 мс: роль, затем текст — `opacity` + `translateY(8px)`;
     - 650–950 мс: кнопка;
     - 800–1100 мс: хедер съезжает сверху. `h1` не начинается с `opacity: 0` (только маска и сдвиг), чтобы не откладывать LCP.
  3. **Реакция аватара на курсор:** по `pointermove` в пределах Hero слой фото внутри маски смещается до 6 px, весь SVG поворачивается до 3°; сглаживание через `requestAnimationFrame` и lerp 0.12; плавный возврат при уходе курсора; обработчик выключается, когда Hero вне viewport.
  4. Все стили интро живут под `[data-intro]`: без JS и без атрибута страница выглядит как сейчас.
- **Приёмка:** интро один раз за сессию; при reduced motion и без JS его нет; LCP растёт не больше чем на 300 мс относительно версии без интро (замер Lighthouse mobile, медиана 5 прогонов); реакция на курсор отсутствует на тач-устройствах.

#### F-14. Смена темы «волной»

- **Оценка:** 3 ч.
- **Что сделать:** при клике по кнопке темы — `document.startViewTransition(() => applyTheme(next))`, затем Web Animations API анимирует `clip-path: circle(0 at x y) → circle(R at x y)` на `::view-transition-new(root)`, где `x, y` — центр нажатой кнопки, `R` — расстояние до дальнего угла экрана; `--dur-slow`, `--ease-in-out`.
  - На время перехода на `<html>` ставится класс, который снимает `view-transition-name` у хедера и `main` (иначе они анимируются отдельно от «волны» и не обрезаются кругом).
  - Существующие cross-document переходы при смене языка не затрагиваются.
  - Фолбэк: без View Transitions API, при reduced motion и при смене системной темы — мгновенно.
- **Приёмка:** волна идёт от нажатой кнопки на десктопе и в мобильном меню; повторный быстрый клик не ломает состояние; в Firefox без API тема меняется мгновенно.

### Волна 2. Header

#### F-03. Скользящая пилюля активного пункта

- **Оценка:** 2 ч.
- **Что сделать:** вместо полоски `.line` под пунктом — плашка за текстом активного пункта (`--accent-alpha`, радиус как у хедера). Позиция и ширина берутся из CSS-переменных, которые выставляет измерение RF-09. Анимируется только `transform` (принцип 2): сдвиг через `translateX`, ширина через `scaleX` с `transform-origin: left`; скругления рисуются псевдоэлементами по краям, которые не масштабируются. `--dur-base`, `--ease-in-out`. На мобильных остаётся текущее подчёркивание.
- **Приёмка:** плашка плавно перетекает при клике и при скролле; после ресайза и загрузки шрифта стоит точно под пунктом; при reduced motion переключается мгновенно.

#### F-04. Smart-hide хедера

- **Оценка:** 2 ч.
- **Что сделать:** при скролле вниз больше чем на 8 px после отметки 120 px хедер уезжает вверх (`translateY(calc(-100% - 20px))`), при скролле вверх возвращается. Хедер **не прячется**, если открыто меню или список языков, если фокус внутри хедера, во время открытой палитры или терминала. Слушатель пассивный, расчёт в `requestAnimationFrame`.
- **Приёмка:** хедер не «дрожит» при мелком скролле трекпадом; клавиатурный пользователь всегда видит хедер, когда фокус в нём; при reduced motion скрытие без анимации.

#### F-05. Шторка мобильного меню справа

- **Оценка:** 3 ч.
- **Что сделать:** мобильное меню (≤ 991 px) выезжает справа: ширина `min(360px, 85vw)`, на всю высоту, `translateX(100%) → 0`, `--dur-slow`, `--ease-out`; оверлей с `backdrop-filter: blur(8px)`. Внутри: пункты меню столбцом, переключатель темы внизу, кнопка закрытия. Focus trap, `Esc`, `inert` и scroll lock — из RF-09. Отступы с учётом `env(safe-area-inset-*)`.
- **Приёмка:** e2e-сценарий меню из `tz.md` проходит без изменений; на iOS Safari нет прокрутки фона под шторкой.

#### F-06. Строка прогресса чтения

- **Оценка:** 1 ч.
- **Что сделать:** линия 2 px по нижнему краю капсулы хедера (внутри скругления), `--accent`, `scaleX(0 → 1)` через `animation-timeline: scroll(root)`. Только под `@supports`, без JS. Скрыта при reduced motion.
- **Приёмка:** линия соответствует позиции скролла; в браузерах без поддержки её нет, и это не ломает хедер.

#### F-07. Кнопка «Наверх» с кольцом прогресса

- **Оценка:** 2 ч.
- **Что сделать:** круглая кнопка 48 px в правом нижнем углу (с учётом `safe-area-inset`), появляется, когда Hero ушёл из viewport (один `IntersectionObserver`). По контуру — SVG-кольцо, `stroke-dashoffset` от `animation-timeline: scroll(root)`; без поддержки — статичное кольцо. Клик: прокрутка наверх (`smooth`, при reduced motion — мгновенно) и перенос фокуса на ссылку-логотип. Локализованный `aria-label`. Не перекрывает уведомление (оно слева) и ripple.
- **Риск:** F-06 и F-07 оба показывают прогресс. На дизайн-ревью решить, оставить ли прогресс в обоих местах; запасной вариант — кольцо без прогресса.
- **Приёмка:** кнопка появляется после Hero и скрывается на нём; фокус после клика наверху страницы.

### Волна 5. Матрица

Тема волны — цифровой дождь из фильма «Матрица». Согласовано с владельцем 30 сентября 2026 (вопросы и живые мокапы в чате). Ядро волны: дождь в Hero, жидкий аватар, надпись из глифов в футере и 404. **Общие правила волны**

- **Цвет** — акцент темы (`--accent-text`: зелёный `#44ff62` в тёмной теме, оранжевый `#ff6433` в светлой; у `--accent` в светлой теме более светлый оттенок `#ff8660`, для текста и глифов он слабее по контрасту). Цвет читается из CSS при старте и при каждой смене темы (атрибут `data-theme` на `<html>` и `prefers-color-scheme`), без перезагрузки эффекта.
- **Глифы** — смесь: полуширинная катакана (`ｦｱｳｴｵｶｷｹｺｻｼｽｾｿﾀﾂﾃﾅﾆﾇﾈﾊﾋﾎﾏﾐﾑﾒﾓﾔﾕﾗﾘﾜ`, вес ×2), символы кода (`{}<>/=;()[]$#*+`), цифры `0–9`. Шрифт — системный `ui-monospace, Consolas, monospace`, новые шрифты не грузятся.
- **Случайность** — детерминированный PRNG (mulberry32) с фиксированным seed. Статичные кадры (reduced motion, пауза, visual regression) одинаковы при каждом прогоне.
- **Декоративность** — все canvas и `<pre>` с глифами имеют `aria-hidden="true"` и `pointer-events: none` (кроме слоя, который ловит hover в M-05). В дерево доступности ничего не попадает.
- **Где остановлено движение** — `prefers-reduced-motion: reduce`, пауза M-04, вкладка скрыта (`visibilitychange`), элемент вне экрана (`IntersectionObserver`). Во всех случаях цикл `requestAnimationFrame` полностью останавливается, а не рисует пустые кадры.

#### M-03. Жидкий аватар

- **Оценка:** 6 ч.
- **Что убирается:** SMIL-морфинг `<animate>` в `Avatar.astro` и наклон аватара до 3° (F-02, п. 3). Сдвиг фото внутри маски до 6 px за курсором **остаётся** как есть.
- **Без JS / до загрузки чанка / reduced motion / пауза:** маска — статичная форма `shapeA` (как сейчас в паузе).
- **Модель:** контур из 14 точек на окружности вокруг центра маски (130, 130) радиусом `R = 120` (единицы `viewBox`). У каждой точки смещение по радиусу `o` и скорость `v`, пружина к цели: `v += (180 × (цель − o) − 9 × v) × dt; o += v × dt` (слабое затухание даёт 2–3 колыхания). Путь — замкнутый Catmull-Rom, переведённый в кубические кривые Безье (`M` + 14 × `C` + `Z`), пишется в `d` у `path` маски.
- **Цель точки** = дыхание + тяга:
  - **Дыхание (вместо SMIL):** `R × (0,045 × sin(1,6t + 1,3i) + 0,03 × sin(0,9t − 2,1i))`, медленное непрерывное «переливание» формы.
  - **Тяга к курсору (мышь):** расстояние от курсора до края `e` (в CSS-пикселях). При `0 < e < 120 px`: `0,5 × R × (1 − e/120) × w`, где `w = max(0, cos(угол точки − угол курсора))^6` — узкий «носик» капли (по первому показу в мокапе 0,87 R, владелец счёл это слишком сильным и попросил ослабить до 0,5 R). Курсор внутри аватара: мягкая вмятина `−0,06 × R × w`.
  - Капля может выходить за пределы `viewBox`: у SVG `overflow: visible`, прямоугольник с градиентом увеличен с запасом; капля рисуется поверх соседних элементов, их раскладка не меняется.
  - Изменение атрибута `d` у пути маски — осознанное исключение из принципа 2 (так же работал SMIL-морфинг): перерисовка ограничена областью аватара, раскладка не пересчитывается.
- **Тач:** тап по аватару — импульс скорости `−5 × R` (в единицах `viewBox` за секунду; вмятина ≈ 30 % радиуса) точкам около точки касания (с тем же весом `w`), форма пружинит ≈ 1 с. Свайп мимо ничего не делает, прокрутка не блокируется (`touch-action` не меняется).
- **Цикл:** подписчик общего тикера M-00; работает, пока Hero на экране и движение разрешено. Координаты курсора берутся из общего `pointermove` на Hero (тот же, что у сдвига фото и фонарика: один слушатель на секцию).
- **Приёмка:** в мокапе v2 значение «растяжение 80» воспроизводится; при уходе курсора форма возвращается к дыханию без рывка; нет наклона; на тач-устройстве тап вызывает колыхание, свайп — нет; unit-тест генератора пути (14 сегментов, замкнут, без `NaN`); при паузе и reduced motion форма `shapeA`.

- **Оценка:** 6 ч.

#### J-02. Сцена «Wake up, Samurai»

- **Приёмка:** e2e (`relic.spec.ts`): открытие по чипу, модальность и фокус, Escape и × до конца сцены — захвата нет, без вмешательства — захват начинается, имя и текст для скринридера, локали, reduced motion (всё сразу, без штрихов), axe.

#### J-03. Захват: палитра, глитчи, SAMURAI, подмена текстов

- **Оценка:** 6 ч.
- **Что сделать:**
  - атрибут `data-relic` на `<html>` переопределяет токены: акцент — неоновый красный, второй цвет — голубой; на светлой теме — свои оттенки с допустимым контрастом текста. Дождь в Hero, блоб, кнопки и ссылки читают токены как при смене темы (общий `accent.ts` следит и за `data-relic`), без перезагрузки эффектов;
  - **глитчи страницы:** раз в 10–15 с (seed, детерминированно) короткий сбой 150–300 мс — сдвиг полосы контента, разделение каналов, сбой одного случайного заголовка. Не в момент, когда пользователь печатает или открыт диалог; не при паузе и reduced motion; не при скрытой вкладке;

- **Приёмка:** e2e: после сцены `data-relic` есть, цвет акцента сменился, дождь перекрашен, логотип показывает SAMURAI и имеет прежнее имя, подменённые тексты видны, а дерево доступности прежнее; с подменой `setTimeout`/часов — глитчи идут с нужным интервалом и прекращаются при паузе; reduced motion — без глитчей; контраст текста в обеих темах не ниже AA (axe).

#### J-05. Darksynth для захвата (Web Audio)

- **Оценка:** 6 ч.
- **Где:** партитура `relic-score.ts` (чистые функции) поверх движка `sound.ts` из S-02 (движок принимает партитуру; если нужно — небольшой рефакторинг без изменения звука таблеток), отдельный чанк `relic-sound`.
- **Звучание (своё, без мелодий из игры):** ми-минор, 112 уд/мин; бас — пилообразные шестнадцатые через дисторшн (`WaveShaperNode`) и low-pass с «открытием» на каждой второй такте; гейтованный пэд на аккордах Em–C–G–D; бочка (синус со спадом частоты) на каждую долю, малый барабан — шум через band-pass на 2 и 4; поверх изредка «гитарный» лид из сатурированной пилы — короткие фразы по seed. Петля 8 тактов с вариациями.
- **Эффекты:** вход в захват — удар и рисер в такт концу сцены; каждый глитч страницы — короткий цифровой «хруст»; выход — музыка «сламывается» вниз по высоте и затухает за 0,6 с.
- **Жизненный цикл:** как S-02: контекст по клику на чип, `suspend()` при скрытой вкладке, `close()` после выхода; планировщик 25 мс только пока захват активен.
- **Бюджет:** чанк `relic-sound` ≤ 4 КБ gzip; потолок громкости как у таблеток.
- **Приёмка:** юнит-тесты партитуры; e2e с заглушкой `AudioContext`: нет контекста до клика, бас и бочка в нужном темпе, хруст на глитч, затухание и закрытие при выходе, нет запросов за аудио.

## 5. Идеи на потом

Не входят в план; к каждой можно вернуться отдельным решением.

- **Страницы кейсов** (`/projects/<id>/`) — отложены владельцем до завершения работы над главной. Первые кандидаты: Dafna, Pomotomo, этот сайт (для него уже есть замеры «до/после» из `tz.md`).
- **Магнитная кнопка CTA** только в Hero — если после F-02 захочется ещё одного акцента.
- **Таймлайн Career, который «рисуется» при скролле** — scroll-driven линия и загорающиеся точки.
- **Превью-видео проекта при наведении** — короткий беззвучный WebM вместо скриншота.
- **Авто-OG-картинки для каждой локали** при сборке.
- **Оверлей горячих клавиш по `?`** — список всех шорткатов (палитра, терминал, навигация).
- **Свайп для закрытия мобильной шторки.**
- **Блок «Сейчас»** — чем занят в данный момент, из JSON.
- **Активность GitHub**, собранная при сборке (без запросов из браузера).

**Рассмотрено для волны 5 и отклонено владельцем:**

- Руки из глифов в футере (как на lukebaffait.fr), в том числе вариант с красной и синей таблетками Морфеуса — заменены надписью MIRISLAMUS (M-05).
- Decode-заголовки секций (проявление из случайных глифов) — накладываются на появление F-01.
- Scramble-перебор букв на ссылках — шумно, мешает скринридерам.
- Аватар, рассыпающийся в глифы, — самый тяжёлый вариант, конкурирует с жидким аватаром.
- Скорость дождя от скорости скролла, Konami-код, команды `matrix`/`wake up` (терминал удалён).
- Цитаты из фильма в скрытых словах дождя (оставлены только призыв и стек).
