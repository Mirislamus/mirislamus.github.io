# Резюме для печати (docs/pages/cv.md)

Функционально-технический паспорт служебной страницы, из которой при сборке печатается PDF-резюме. Реализация — `src/pages/cv/[lang].astro` и `src/widgets/components/Cv/Cv.astro`.

---

## 1. Паспорт страницы и метаданные

- **URL маршрута:** `/cv/en/`, `/cv/ru/`, `/cv/uz/`. Посетителю отдается не страница, а файл `/cv/mirislam-usmanov-<locale>.pdf`.
- **Назначение страницы:** источник PDF-резюме для кнопки «Скачать резюме» в Hero.
- **Тип рендеринга:** SSG; после сборки `scripts/render.mjs` печатает каждую страницу в PDF через Chromium (Playwright), лимит файла — 300 КБ.
- **SEO-метаданные:** `<meta name="robots" content="noindex, nofollow">`; страницы нет в sitemap.
- **Оформление:** светлая схема, формат страницы задает CSS для печати (`preferCSSPageSize`).

---

## 2. Структура страницы

1. `<h1>` — имя, должность и контакты.
2. `<h2>` — кратко о себе (`src/data/cv/cv.json`).
3. `<h2>` — опыт: места работы в обратном порядке (`src/data/career/`).
4. `<h2>` — проекты (`src/data/projects/`).
5. `<h2>` — навыки (`src/data/skills/`).
6. `<h2>` — образование и `<h2>` — языки (`src/data/cv/cv.json`).

Тип компонента — статический `.astro`, без клиентского JS. Данные те же, что у главной страницы (`getSiteData`).

---

- [x] PDF собирается для трех языков; больше 300 КБ — `scripts/render.mjs` бросает ошибку, сборка пишет предупреждение, а `tests/e2e/cv.spec.ts` падает.
- [x] Страница закрыта от индексации, полная и без лишних персональных данных; PDF небольшой, со встроенным Inter и настоящим текстом (`tests/e2e/cv.spec.ts`).
- [x] Кнопка в Hero скачивает PDF на языке страницы (`tests/e2e/cv.spec.ts`).
