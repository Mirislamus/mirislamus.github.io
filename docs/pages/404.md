# Страница 404: Не найдено (docs/pages/404.md)

Функционально-технический паспорт страницы ошибки 404 (Not Found). Реализация — `src/pages/404.astro`, тесты — `tests/e2e/not-found.spec.ts`.

---

## 1. Паспорт страницы и метаданные

- **URL маршрута:** `/404` (обрабатывает любые несуществующие адреса).
- **Назначение страницы:** понятное объяснение ситуации пользователю и возврат на главную на его языке.
- **HTTP-статус сервера:** строго **404 Not Found**. Astro собирает `src/pages/404.astro` в `404.html`; GitHub Pages отдает его со статусом 404 для любого несуществующего адреса.
- **Языки:** одна статическая страница на все языки (у GitHub Pages один `404.html`). В разметке три блока текста (EN, RU, UZ); инлайн-скрипт показывает блок по языку из адреса (`/ru/...`), иначе по языку браузера, иначе английский. Без JavaScript — английский.
- **SEO-метаданные:**
  - `<title>`: 404 — Mirislam Usmanov
  - `<meta name="robots" content="noindex" />` — страница не индексируется; переход по ссылкам разрешен по умолчанию.
  - Страницы нет в `sitemap.xml`.

---

## 2. Структура и компоненты страницы

Страница — отдельный документ без `Layout`, шапки и подвала: заставка в стилистике Matrix ([ADR 0024](../decisions/frontend/0024-site-deviations.md) §4).

1. **Фон:** `<canvas data-backdrop>` с дождем глифов (`@shared/scripts/matrix/backdrop-fx`, загружается динамическим импортом последним, `aria-hidden`).
2. **Код ошибки:** `Wordmark` «404» из глифов.
3. **Подпись:** «There is no spoon.» (`lang="en"` на всех языках).
4. **Блок текста на каждом языке** (`<section lang>`, видим один):
   - `<h1>`: «Page not found» / «Страница не найдена» / «Sahifa topilmadi»;
   - пояснение: «This page does not exist or has moved.» / «Такой страницы нет или она переехала.» / «Bunday sahifa yo‘q yoki ko‘chirilgan.»;
   - кнопка `Button` — ссылка на главную этого языка: «Go to the home page» / «На главную» / «Bosh sahifaga».
5. **Пауза анимации:** `MotionToggle` (WCAG 2.2.2).
6. **Тема:** применяется инлайн-скриптом до отрисовки, как на главной.
