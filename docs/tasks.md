# Задачи и прогресс

Ветка: `refactor/site-v2`. Процесс: одна задача → коммит → отчёт → ожидание «дальше». Пуш и мёрж в `master` — только с разрешения владельца (пуш в `master` деплоит сайт).

Статусы: ⬜ не начата · 🔄 в работе · ✅ готова (коммит) · ⏸ ждёт владельца

Подробные требования и критерии приёмки — в [`tz.md`](./tz.md) (RF-xx) и [`features.md`](./features.md) (F-xx).
