## ⚡ Ключевые направления трансформации (/boost)

1. **Zero-JS Архитектура (Astro Islands):**
   - Перевод оставшихся интерактивных островов (`Approach`, `Career`, `Projects`, `Reviews`) на нативный Astro HTML/CSS.
   - Замена тяжелых сторонних рантаймов (`Swiper`, `Sonner`, `motion`) на нативные стандарты (CSS Scroll-Snap, нативный `<dialog>`, микро-скрипты).
   - Сокращение начального бандла JavaScript со **171 КБ gzip до < 35 КБ gzip**.

2. **Физика естественных движений (Spring Motion Design):**
   - Токены плавности `cubic-bezier(0.16, 1, 0.3, 1)` и пружинные отклики.
   - Магнитные кнопки и интерактивный курсорный блик (Spotlight / Specular Sheen).
   - 3D-tilt карточек и органический морфинг аватара с мгновенным отключением при `prefers-reduced-motion: reduce`.

3. **Бескомпромиссная доступность (WCAG 2.1 AA):**
   - Калибровка `--accent-text: #c84010` (контраст > 5:1 на белом) и `--text-muted: #595959` (контраст 7:1) для 100% устранения нарушений контраста в светлой теме.
   - Навигация без мыши (полноценный `focus-visible`, Focus Trap в мобильном меню, закрытие по `Escape`).
   - Четкая семантическая иерархия заголовков без пропусков (`h1` → `h2` → `h3`).

4. **Компонентные редизайны:**
   - **Header:** Парящий стеклянный капсульный бар (Floating Island Glassmorphism), скользящая активная пилюля, шторка меню.
   - **Hero:** Выразительная типографика, статус-бейдж "Available for work" с радарным пульсом, живой интерактивный аватар.
   - **Approach:** Bento Grid 2.0, интерактивная UI-craft песочница, мгновенное копирование email с морфингом иконки.
   - **Career & Reviews:** Нативные доступные CSS Scroll-Snap карусели вместо тяжелого Swiper.
   - **Projects:** Кинематографичные превью 16:9, метрики личного вклада, раскрытие без задержек.
   - **Skills:** Матрица компетенций по 4 доменам, удаление визуального шума.
   - **Footer:** Минималистичный темный стиль, виджет локального времени (Tashkent UTC+5), кнопка "Наверх" с progress ring.

5. **Очистка ассетов и репозитория (Asset Hygiene):**
   - Удаление 387 КБ неиспользуемых шрифтов SF Pro из `public/fonts/`.
   - Оптимизация 137 КБ векторного файла `zustand.svg` через SVGO до < 3 КБ.
   - Сжатие 8 МБ несжатых оригинальных JPG в `public/images/projects/`.

## 🛠️ Команды проверки качества

Для валидации кодовой базы используются следующие команды:

```bash
# Проверка типов Astro и TypeScript
bun run check

# Проверка качества кода ESLint
bun run lint

# Автоматическая проверка целостности внешних ссылок
bun run check:links

# Чистая продакшн-сборка всех локалей (EN, RU, UZ) и генерация sitemap
bun run build
```
