## 🧭 1. Видение и цели модернизации (/boost)

Текущий сайт представляет собой качественное персональное портфолио, однако архитектурно и визуально он может быть выведен на принципиально иной уровень:
- Перегружен лишними рантаймами (Framer Motion v12, Swiper, Sonner, @gsap/react), передавая **~171 КБ gzip JavaScript** на первом экране для одностраничного контента.
- Использует стандартные линейные CSS-переходы (`0.25s ease-in`), лишая интерфейс ощущения физичности, премиальности и веса.
- Имеет подтверждённые недочёты контрастности в светлой теме (акцентный оранжевый `#ff6433` даёт контраст лишь 2.96:1 на белом при норме WCAG AA ≥ 4.5:1).
- Содержит визуальный шум в навыках (браузеры, мессенджеры) и неиспользуемые ассеты (387 КБ неиспользуемых шрифтов SF Pro в `public/fonts/`, 137 КБ векторный `zustand.svg`, ~8 МБ несжатых JPG-фоллбеков).

**Главная цель /boost:**  
Трансформировать сайт в витрину инженерного мастерства мирового уровня, демонстрирующую:
1. **Zero-JS Архитектуру:** радикальное сокращение клиентского JS до **< 35 КБ gzip** через Astro Islands и нативные браузерные стандарты.
2. **Физику естественных движений:** пружинные кривые Безье, тактильный отклик, 3D-наклон карточек, магнитные кнопки и световые блики (Specular Sheen).
3. **Бескомпромиссную доступность (WCAG 2.1 AA):** выверенный контраст, полноценная навигация с клавиатуры, поддержка скринридеров и строгая обработка `prefers-reduced-motion`.
4. **Премиальный UI/UX дизайн:** эстетика темного технологичного минимализма (Linear/Stripe), асимметричный Bento Grid 2.0, кинематографичные кейсы и интерактивные микро-виджеты.

## ⚡ 2. Архитектура: Zero-JS by Default (Astro Islands)

### 2.1. Аудит текущего состояния и стратегия де-гидратации

В текущей кодовой базе компоненты `Hero.astro`, `Skills.astro` и `Footer.astro` уже являются нативными компонентами Astro. Однако на главной странице `src/pages/[...lang]/index.astro` по-прежнему подключаются с директивой `client:visible`:
- `Approach.tsx` (React) — статическая сетка, гидрирующаяся только ради копирования email и переключения картинки кода.
- `Career.tsx` (React) — Swiper карусель, тянущая более 85 КБ Swiper JS/CSS.
- `Projects.tsx` (React) — гидрируется ради кнопки «Показать ещё» с искусственным таймером и скелетонами.
- `Reviews.tsx` (React) — Swiper карусель с пагинацией.
- `ToastProvider.tsx` (React) — Sonner тостер.

### 2.2. План де-гидратации по компонентам

| Компонент | Текущий стек | Целевой стек (/boost) | Экономия JS (raw / gzip) |
| :--- | :--- | :--- | :--- |
| **Approach** | React 19 + Lucide + Sonner | Чистый `Approach.astro` + микро-скрипт копирования email (`<copy-email>`) | ~18 КБ / ~6 КБ |
| **Career** | React 19 + Swiper + ArrowControls | `Career.astro` + нативный CSS Scroll-Snap (`scroll-snap-type: x mandatory`) | ~95 КБ / ~28 КБ |
| **Projects** | React 19 + Spotlight + Skeleton | `Projects.astro` + нативное раскрытие через CSS/HTML | ~14 КБ / ~4 КБ |
| **Reviews** | React 19 + Swiper Pagination | `Reviews.astro` + нативный CSS Scroll-Snap с индикаторами | ~85 КБ / ~25 КБ |
| **Toaster** | `sonner` (`ToastProvider.tsx`) | Нативный микро-тост на базе `<dialog>` или CSS-анимации (~40 строк JS) | ~34 КБ / ~10 КБ |
| **Motion** | `motion` (Framer Motion v12) | Удаление неиспользуемого пакета и `LazyMotionWrapper` | ~75 КБ / ~22 КБ |

**Суммарный эффект:** снижение стартового веса страницы на клиенте более чем на **130 КБ gzip**, время парсинга JS стремится к 0 мс на мобильных устройствах.

## 🌊 3. Дизайн-система движения и анимационная физика

### 3.1. Токены естественных пружин (Spring Curves)

Отказ от линейных и примитивных `ease-in` переходов. Вводятся специализированные кривые в `src/styles/helpers/_variables.scss`:

```scss
// Естественные пружинные кривые (Spring Motion Tokens)
--ease-spring-soft: cubic-bezier(0.16, 1, 0.3, 1);    // Мягкое демпфирование для модалок, шторок и раскрытия
--ease-spring-snappy: cubic-bezier(0.2, 0.8, 0.2, 1); // Быстрый упругий отклик для кнопок, вкладок и пилюль
--ease-spring-bounce: cubic-bezier(0.34, 1.56, 0.64, 1); // Микро-подпрыгивание для иконок и бейджей
--ease-out-expo: cubic-bezier(0.19, 1, 0.22, 1);     // Мгновенный выход для быстрого закрытия

// Длительности микровзаимодействий
--duration-instant: 120ms;
--duration-fast: 200ms;
--duration-base: 320ms;
--duration-slow: 500ms;
```

### 3.2. Магнитные кнопки (Magnetic Physics)

Для ключевых кнопок действия (Главный CTA в Hero, переключатели в Header, кнопки копирования и контактов) вводится эффект физического притяжения к курсору:
- **Радиус захвата:** 30–40px от центра кнопки.
- **Предельное смещение кнопки:** 6–8px с затухающей интерполяцией (lerp 0.15).
- **Параллакс содержимого:** иконка и текст внутри кнопки смещаются на дополнительные 2–3px в сторону курсора, создавая ощущение глубины.
- **Ограничение:** мгновенный возврат с упругим колебанием при выходе курсора из зоны; автоотключение на тач-устройствах (`@media (hover: hover) and (pointer: fine)`).

### 3.3. Spotlight & 3D Tilt Карточек (Specular Highlight)

Для карточек проектов и элементов Bento Grid:
1. **Световой блик (Specular Sheen):** Тонкий градиентный блик по контуру 1px границы (`radial-gradient(400px circle at var(--mouse-x) var(--mouse-y), rgba(255,255,255,0.12), transparent 40%)`).
2. **3D Tilt (Микро-наклон):**
   - Перспектива: `perspective: 1000px`.
   - Вращение: `rotateX` и `rotateY` в диапазоне от `-4deg` до `+4deg` в зависимости от расстояния от центра карточки.
   - Сглаживание через `requestAnimationFrame` с интерполяцией.
   - Запрет наклона на мобильных экранах и при сниженном движении.

### 3.4. Аватар: Оптимизация GSAP и 3D-параллакс

Текущий аватар (`src/shared/ui/Avatar/Avatar.tsx`) содержит таймлайн GSAP MorphSVG.
Спецификация улучшений:
- Инициализировать анимацию GSAP **только** после проверки `window.matchMedia('(prefers-reduced-motion: no-preference)').matches` и только когда аватар вошёл в область видимости (`IntersectionObserver`).
- При уходе аватара из зоны видимости — ставить GSAP таймлайн на паузу (`timeline.pause()`), экономя батарею и CPU устройства.
- Добавить эффект слежения: при движении мыши по первому экрану слой фото внутри SVG-маски смещается с легким 3D-параллаксом (`translate(-50%, -50%) translate3d(dx, dy, 0)`).
- При `prefers-reduced-motion: reduce` отображается статическая элегантная органическая фигура без малейшей нагрузки на CPU.

## 🎨 4. Дизайн-система, WCAG 2.1 AA и Контрастность

### 4.1. Калибровка токенов светлой темы

В ходе аудита выявлено 23 нарушения контрастности в светлой теме:
- Акцентный цвет `--accent: #ff6433;` на белом фоне имеет контраст **2.96:1** (не проходит AA для текста).
- Вторичный текст местами использует `#9a9a9a` (контраст **2.5:1**).

**Требования к палитре:**
1. Разделить визуальный акцент (фон/бордеры) и текстовый акцент:
   - Декоративный акцент остаётся оранжевым: `--accent: #ff8660;` (light) / `--accent: #44ff62;` (dark).
   - Текстовый акцент для светлой темы: `--accent-text: #c84010;` (контраст **5.03:1** на белом — проходит WCAG AA с запасом).
   - Текстовый акцент для тёмной темы: `--accent-text: #44ff62;` (контраст **11.8:1** на `#121212`).
2. Вторичный приглушённый текст:
   - Светлая тема: `--text-muted: #595959;` (контраст **7.0:1** — уровень AAA).
   - Тёмная тема: `--text-muted: #9a9a9a;` (контраст **5.1:1** — уровень AA).
3. Акцентные кнопки с заливкой:
   - В светлой теме использовать инверсный темный текст `--accent-contrast: #121212;` на кнопке с оранжевой заливкой, обеспечивая читаемость свыше 6:1.

### 4.2. Системная интеграция и zero-FOUC

- CSS-свойство `color-scheme: light` / `color-scheme: dark` синхронизируется на теге `<html>`.
- Метатег `<meta name="theme-color">` динамически обновляется при переключении темы (`#ffffff` для light, `#121212` для dark).
- Критический инлайн-скрипт в `<head>` применяет сохранённую тему из `localStorage` до первой отрисовки DOM, исключая ночное мигание белым экраном (FOUC).

## 📐 5. Компонентные спецификации и Редизайн

### 5.1. Header: Парящий остров (Floating Island Navigation)
- **Конструкция:** Плавающий капсульный бар с отступом сверху (`top: 16px; margin: 0 auto; max-width: 1040px; border-radius: 9999px;`).
- **Стеклянный эффект (Glassmorphism):** `backdrop-filter: blur(16px) saturate(180%); background: rgba(var(--bg-rgb), 0.72); border: 1px solid rgba(255, 255, 255, 0.08);`.
- **Smart Hide при скролле:** При скролле вниз более чем на 80px хедер плавно скрывается наверх (`transform: translateY(-120%)`), при малейшем скролле вверх — мягко возвращается (`transform: translateY(0)`).
- **Скользящая пилюля (Sliding Active Pill):** Замена статической подчеркивающей полоски на полупрозрачную плашку за текстом, скользящую между ссылками с пружинным переходом `transition: transform 300ms var(--ease-spring-snappy), width 300ms var(--ease-spring-snappy)`.
- **Шторка мобильного меню (Mobile Drawer):**
  - Размытый полупрозрачный фон.
  - Полноценный клавиатурный Focus Trap (уже заложен в коде, требует визуальной доводки).
  - Плавный выезд справа с эффектом пружины.
  - Взаимное исключение: при открытии меню закрывать переключатель языков и наоборот.
