# Структура шаблона проекта

Файлы шаблона ai-template в репозитории сайта. Документация разделена на постоянные правила, описание продукта, устройство кодовой базы и текущее состояние работ. Код сайта (`src/`, `scripts/`, `tests/`, `public/`, `.github/`) описан в [ARCHITECTURE.md](ARCHITECTURE.md) и [README.md](README.md).

## Файлы шаблона

```text
PROMPT.md               # Промпт допроса по продукту для пробелов PRODUCT.md и новых функций
TEMPLATE_STRUCTURE.md   # Эталонная структура файлов репозитория
USAGE.md                # Пошаговое руководство по использованию шаблона

AGENTS.md               # Регламент взаимодействия и поведения AI-агентов
PRODUCT.md              # Паспорт и бизнес-требования к продукту
ARCHITECTURE.md         # Структура src/ сайта и реестр ADR
README.md               # Главная инструкция по командам и окружению
STATE.md                # Текущий статус проекта

.editorconfig           # Отступы, LF, кодировка
.gitattributes          # Единые LF-окончания строк
.gitignore              # Артефакты сборки, секреты, служебные файлы
.prettierrc             # Конфигурация форматирования (значения сайта, см. задачу 023)
.env.example            # Шаблон переменных окружения (у сайта переменных нет)

.claude/
├── settings.json       # Настройки Claude Code: коммиты и PR без соавторства AI (ADR 0011)
└── agents/             # Субагенты Claude Code: planner, explorer, frontend-dev(-deep), backend-dev(-deep), reviewer, qa

docs/
├── tech.md             # Технологический стек и одобренные библиотеки
├── setup/              # Развертывание через Bun и эталонные конфиги
│   ├── common.md       # Структура репозитория, package.json, Prettier, окружение
│   ├── frontend.md     # Astro / Next.js, линтеры, тесты, базовые стили и токены
│   └── backend.md      # Elysia, Drizzle, Docker Compose, бэкапы
├── skills.md           # Регламент AI-навыков и их совместимость с проектом
├── workflow.md         # Уровни сложности, разбиение задач, субагенты
├── design.md           # Дизайн-система: сетка, токены, состояния, анти-шаблоны
├── quality.md          # Чеклист качества, пороги Lighthouse, кроссбраузерность
├── seo.md              # Оперативные SEO-стандарты страниц, OpenGraph
├── content.md          # Типографика, инфостиль, согласие на обработку данных
├── tasks.md            # Индекс задач: уровень, статус, ссылка на карточку
├── tasks/              # Карточки задач уровня Medium и выше
│   ├── task-template.md
│   └── 001-ai-template-adoption.md  # Внедрение шаблона и аудит расхождений
├── pages/              # Паспорта страниц
│   ├── page-template.md
│   ├── 404.md          # Страница 404 сайта
│   ├── privacy-policy.md          # Не нужна, пока нет форм и аналитики
│   └── personal-data-consent.md   # Не нужна, пока нет форм и аналитики
└── decisions/          # Реестр архитектурных решений (ADR), перечень — в ARCHITECTURE.md
    ├── frontend/       # Фронтенд: HTML, SCSS, React, состояние, формы, SEO, аналитика; 0024 — отступления сайта
    ├── backend/        # Бэкенд: архитектура, API, БД, авторизация, безопасность (бэкенда у сайта нет)
    └── common/         # Общее: TypeScript, линтинг, зависимости, Git, Bun, тесты, деплой
```

`PROMPT.md`, `TEMPLATE_STRUCTURE.md` и `USAGE.md` — служебные файлы шаблона, адаптированные под сайт. Остальные файлы описывают сам сайт.
